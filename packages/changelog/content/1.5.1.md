## Microsoft 365 calendar

- Connecting a Microsoft 365 or Outlook calendar works again. The 1.5.0 build
  was produced without the Microsoft app credentials, so the app reported the
  feature as not set up and the button did nothing
- Nothing about the calendar feature itself changed; it was only missing from
  the released build

## Also in this release

- Builds are Apple Silicon only. An Intel Mac cannot install or update to this
  version
